# GovToolsPro Skills

Agent Skills that guide Claude in using the GovToolsPro MCP connector
(`https://mcp.govtoolspro.com/api/mcp`).

| Skill | Description |
|---|---|
| [federal-opportunity-triage](./federal-opportunity-triage/SKILL.md) | Bid/no-bid triage workflow for U.S. federal opportunities — pull a SAM.gov solicitation, score it go/no-go, identify the incumbent and competition, benchmark the market and labor rates, and find teaming partners. |
